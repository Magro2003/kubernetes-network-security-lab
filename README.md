# Kubernetes Network & Security Lab

Engineering project focused on building and progressively extending a practical Kubernetes laboratory.

## Initial scope

The project will demonstrate:

* containerized application deployment,
* Kubernetes Deployments and Services,
* basic Kubernetes networking,
* troubleshooting techniques,
* selected networking and security mechanisms.

## Project structure

* `app/` – demo application
* `k8s/` – Kubernetes manifests
* `docs/` – project documentation and diagrams
